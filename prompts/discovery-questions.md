---
type: prompt
title: Discovery Questions
---

Generate a set of discovery-call questions tailored to the customer in the current note (or one I name in chat).

Use the customer's `industry`, `tier`, and any captured context to focus the questions. Produce:

1. **Business Context** (5-7 questions) — strategic priorities, organisational structure, how success is measured.
2. **Current State** (5-7 questions) — incumbent tools, pain points, gaps, what's working.
3. **Technical Environment** (5-7 questions) — architecture, data sources, integrations, hosting model, security posture.
4. **Stakeholders & Decision Process** (3-5 questions) — economic buyer, technical buyer, influencers, evaluation criteria, timeline.
5. **Constraints** (3-5 questions) — budget signals, regulatory, compliance, change-management appetite.

Tailor wording to the industry. Avoid yes/no questions. Group questions logically and number them so they can be referenced in the meeting note.

If the customer note already documents an answer to one of the questions, drop that question and replace it with a deeper follow-up.
